## Third-party code

- `src/savefile.c/.h` GAME0 codec and `tests/game_save_fixture.py`: wire order and record definitions follow RSD's `code/GM/PLAYGAME.C`, `CHAR.H`, `MAP.H`, `GMGEN.H`, `BLOC.H`, `COORD2D.HPP` and `code/DRV/GEN.H` in GameMaker-SandboxEdition at `7f614cfbfa5c8c15c83d586a46edf57af79d1afc` (MIT source, copyright (c) 2014 gandrewstone; (c) 2026 Lewis Moten modifications). The public shipped DOS executable independently corroborates packed record widths. The codec and synthetic structural fixtures are new; no original executable, game save, or private-reference bytes are imported. See `docs/game-save.md` for provenance and the distinction between wire preservation and live gameplay restoration.

- `src/voc_host.c`: container/PCM8/repeat behavior follows Sandbox Edition's `web/packages/engine/src/formats/voc.ts:1-125`, linear resampling follows `audio/engine.ts:273-295`, and stop/retrigger semantics follow Peter Savage/RSD's `code/GM/SOUNDC.C:153-253`, read at `c97a75265160776318fdde804134b22b01c3fe40` (MIT source, copyright (c) 2014 gandrewstone; (c) 2026 Lewis Moten modifications). The bounded owned-source/index/parser, fixed-point rendering and saturating mixer are original here. VOC is Creative Technology Ltd.'s format; no specification prose, Creative driver, ADPCM tables or third-party implementation is imported. Existing CD audio remains its authors' work and is used only as private source-referenced oracle evidence, not relicensed or copied into this repository. See `docs/voc-host.md` for explicit unsupported encodings and web codec/channel-check omissions. This component remains unlinked.

- `src/pcspeaker.c`: format, 36-step timing and speaker level behavior follow RSD's `code/GM/SOUND.H` (Oliver Stone) and `PLAYGAME.C`, plus Sandbox Edition's `formats/sound.ts`, `audio/cmfPlayer.ts` and `audio/engine.ts` at commit `5353512a5b8e87e72321c8a0ba87c5443ef878eb` (MIT, copyright (c) 2014 gandrewstone; (c) 2026 Lewis Moten modifications). The integer oscillator/rational-clock implementation is original here, not a browser oscillator port. This producer remains unlinked. See `docs/pcspeaker-host.md` for source coordinates and fidelity limits.


- `src/vocplay.c`, `tools/voc_compare.ts`: a streaming C port of the Sandbox Edition's `formats/voc.ts` (`decodeVoc`, with its ADPCM tables from the Sound Blaster DSP as DOSBox's `sblaster.cpp` implements them) and the level and cutting rules of `audio/engine.ts` `playVoc` (MIT, copyright (c) 2014 gandrewstone; (c) 2026 Lewis Moten modifications), which stand in for the Creative driver RSD's `PlaySbVocFile()` in `SOUNDC.C` handed the file to. Written with Claude Sonnet 5.5 (Anthropic).
- `src/opl.c`, `src/cmf.c`, `tools/make_opl_tables.py`: C ports, in integer math, of the Sandbox Edition's `web/packages/engine/src/audio/opl.ts`, `cmfPlayer.ts` and `cmfLoad.ts` (MIT, copyright (c) 2014 gandrewstone; (c) 2026 Lewis Moten modifications), which port PlayIt() of RSD's `code/GM/SBMUSIC.C`. No Nuked-OPL, DOSBox or other emulator code is used. `tools/make_ostune.ts` uses that repository's song tools (`music/compose.ts`, `kit/song.ts`).
- **Silkscreen** (The Silkscreen Project Authors, SIL Open Font License 1.1), bundled as WOFF2 in `docs/fonts/` (from the `@fontsource/silkscreen` 5.1.0 package) for the project page's headings; the license text is `docs/fonts/OFL-Silkscreen.txt`. The page's pictures are made from the art in `art/` (ChatGPT GPT-6.1 Sol, credited above) and host renders of the games list, which show Game-Maker: Sandbox Edition Starter games (MIT).
- `sdk/`: the sandbox-kernel SDK (headers, `crt0.S`, `mem.c`, link map), MIT, copyright (c) 2026 Lewis Moten; the commit is in `sdk/PINNED`.
- `tools/font.txt`: the capitals, digits and `- : . /` come from sandbox-kernel's 5x7 status font (MIT, same author).
- `third_party/gmcore/` (`gmcore.h`, `gmmon.h`): the play core of the Pocket Player in [Game-Maker: Sandbox Edition](https://github.com/lewismoten/GameMaker-SandboxEdition), copied unchanged at the commit in `third_party/gmcore/PINNED`, with that repository's MIT license (`third_party/gmcore/LICENSE`: copyright (c) 2014 gandrewstone; copyright (c) 2026 Lewis Moten for the modifications). It ports that project's web engine, which follows `PLAYGAME.C` from RSD Game-Maker 3.0 (Recreational Software Designs, 1991-1995), whose source was released under the MIT License in 2014. The two files were written with Claude Sonnet 5.5 (Anthropic), as that repository's history and NOTICE.md record.
- `src/gif.c`: a C port of that repository's GIF decoder (`web/packages/engine/src/formats/gif.ts`, MIT, same license as above), which mirrors `GIFC.C` from the same RSD source.
- `src/gif.c` also draws an image of any size through a 320 x 200 window, as that repository's `Screen.drawImage` does for backdrops.
- `src/fli.c`: a C port of that repository's FLI decoder (`formats/fli.ts`, MIT, as above), which follows `code/Image/FLI/FLI.CPP` from the RSD source.
- `src/text.c`, `src/session.c`: the text pages, fades and page order port that repository's `engine/showGraphic.ts` (`showGraphic`, `displayFile`, `playFli`), `engine/machine.ts` (`fadeTo`), `gfx/screen.ts` (`write`), `formats/graphicScripts.ts` (`textLines`, backdrops, slide lists) and `formats/palette.ts` (`matchColor`), MIT as above; those follow `ShowGraphic`, `Display_File` and `FadeTo` in RSD's `PLAYGAME.C`.
- `src/font8_data.c`: characters 0 to 127 of that repository's 8 x 8 font (`gfx/cp437Glyphs.ts`, MIT): printable ASCII from Daniel Hepper's public-domain font8x8 (github.com/dhepper/font8x8), the rest drawn for that project.
- `src/thumb.c`: chooses a game's title screen the way that repository's `gfx/titlePicture.ts` and `gfx/levelPicture.ts` (`busyness`) do, and boxes it down the way its `export/pocketThumbnail.ts` does (MIT, as above); the code is new. `src/library.c` reads that repository's Pocket Player library format (`export/pocketLibrary.ts`); the reader is new. `src/view.c` follows the look of that repository's Games page (`editor/shell/homeCategories.ts` gives the tabs' lines, shortened); the drawing is new.
- `src/game.cpp`: converts a pre-3.00 `.GAM` file the way that repository's `parseGame` and `serializeGame` do (after `GameClass::Load` in RSD's source); reads the `.GAM` layout as that repository's `formats/game.ts` documents it (from RSD's `GRATOR.H`) and builds levels the way its Pocket Player packer does; the code is new.
- `tests/games/DICE/`: the DOS files of the Starter game "Roll the Dice" from Game-Maker: Sandbox Edition (MIT, as above; the game's own `LICENSE.TXT` is included), used as a test fixture. `tests/data/dice-old.gam` is the same game's `.GAM` rewritten in the pre-3.00 layout for the tests. `tests/data/pictures-ref.txt` holds hashes that the Sandbox Edition engine's own code computed from that game's and other Sandbox Edition games' files, and from the shareware `.GAM` files on RSD's CD in that repository. `tests/data/library.jsl` holds that game's library line as that repository's `web/scripts/gmosCard.ts` wrote it, with test lines. `tests/data/dice-pocket.txt` and `dice-cards.txt` are output of that repository's Pocket Player host test and packed data (`tools/pocket_reference.py`).
- `third_party/gmcore/gmsmall.h`: the Pocket Player's bundle reader from the same repository and commit, copied unchanged; it reads the index of a `.GMP`.
- `third_party/puff/`: puff 2.3, the small inflater from [zlib](https://github.com/madler/zlib) 1.3.1's `contrib/puff`, copied unchanged (`PINNED`), zlib License, copyright (C) 2002-2013 Mark Adler; the license text is in `puff.h` and `puff.c`. It inflates the DOS files in a `.GMP`.
- `third_party/quickjs-ng/`: [QuickJS-ng](https://github.com/quickjs-ng/quickjs) v0.18.0 (engine sources only, unchanged; `PINNED`), MIT License, copyright (c) 2017-2026 Fabrice Bellard, (c) 2017-2024 Charlie Gordon, (c) 2023-2026 Ben Noordhuis and the other QuickJS-ng authors; the full license text is `third_party/quickjs-ng/LICENSE` and travels with `JS.ELF`.
- `JS.ELF` links newlib's C library and math library (`libc.a`, `libm.a`) from the Arm GNU Toolchain 15.3.rel2. Newlib is under a set of BSD-style and similar permissive licenses listed in its [COPYING.NEWLIB](https://sourceware.org/newlib/COPYING.NEWLIB) (the math functions come from Sun's fdlibm: "Permission to use, copy, modify, and distribute this software is freely granted, provided that this notice is preserved").
